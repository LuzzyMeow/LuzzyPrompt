# 坑位、许可与边界

## 一、三个静默坑位（不报错，但结果错）

### 坑位 1：认知资产被 `.gitignore` 掉 → 索引静默建不起来

`scan` 按 **Git 忽略权威**取文件清单。把以下任何一个加进 `.gitignore` 或
`.git/info/exclude`，它们会被**静默跳过**：

```text
aoci.txt
aoci.meta.txt
aoci.code.txt
aoci.database.txt
AGENTS.md
```

**症状**：`scan` 成功返回，但索引是空的或条目不全，**没有任何报错**。
**处置**：移出忽略清单后重扫。`init` 自己写的**宿主配置忽略项保持原样**——那部分是应该忽略的。

### 坑位 2：宿主配置含本机绝对路径 → 提交后污染别人

接入时写的配置（`.mcp.json` / `.claude/settings.json` / `.codex/config.toml` /
`opencode.json`）里的命令与仓库路径都是**本机绑定的绝对路径**。

- **必须 gitignore、不要提交**：提交后的副本在任何其他机器上都会失效
- **更麻烦的是幂等判断**：接入器按**条目是否存在**判断是否已配置，
  所以在坏路径的机器上重跑接入会**静默保留坏路径**
- **处置**：删掉那条配置再重建

### 坑位 3：「只读」命令 ≠ 零文件写入

`verify` / `check` / `index score` / `index inventory` 的「只读」意思是
**不修改正式索引或基线**，**不等于严格零文件写入**：

- 账本启用时这四个都可能**追加本地账本**
- `verify` 还会尝试写**校验历史**
- 审计写入失败**不改变**既有退出码与治理判据

**要严格零文件写入，就用隔离副本。** 当前公开命令面**没有**一次性关闭所有
账本与校验历史写入的总开关。

## 二、许可：FSL-1.1-MIT（Fair Source）

**准确说法**：Fair Source / source-available，**不是** OSI 认可的开源许可。

| 项 | 内容 |
|---|---|
| 全称 | Functional Source License, Version 1.1, MIT Future License |
| 允许 | 内部使用与访问、非商业教育、非商业研究、按条款为被许可人提供专业服务 |
| **限制** | **竞争性用途**——把它做成替代本软件、替代其商业服务、或提供相同/实质相似功能的商业产品或服务 |
| 未来许可 | 软件发布**满两年**后，自动获得 MIT 许可 |
| 再分发 | 必须附带条款副本或链接，不得移除版权声明 |
| 商标 | 无商标授权（仅可标注来源） |

**引导用户时要如实说明这三件事**（耗时 / 许可 / 写入面），
**不许**为了让用户同意而只说「开源免费」。

## 三、非 git 仓库

`scan` 依赖 Git 忽略权威取文件清单——**没有 git 就建不起索引**。

如实说明并**跳过**，不尝试变通（比如手工维护文件清单）。
转入普通探索推进任务。

## 四、数据库访问边界

| 项 | 边界 |
|---|---|
| 触发 | 必须**显式**命令才连；未配置时不进行任何数据库网络访问 |
| 读取 | **只读基础表的结构元数据**；不读业务行、不读视图/例程/注释 |
| 写入 | **不执行 DDL / DML** |
| 凭据 | 只通过**环境变量名引用**，从不保存、从不写入认知资产、从不在对话里索取 |
| 离线 | 数据库认知的写入**离线运行**，写入时不重新连接数据库 |
| openGauss | 仅 6.0.5 LTS、A/PG 兼容模式、普通非分区基础表；不支持的目录特性**失败关闭**，不静默降级 |

**用户不该被要求粘贴连接串。** 用户只声明数据源的非敏感身份，AOCI 给出稳定的
环境变量引用名；数据库管理员在**外部**提供该变量并授予最小权限只读账号。

## 五、隐私与数据出口

- **本地优先**：没有默认云端点、没有托管源码上传服务、没有必须运行的后台服务器
- **不联网**：唯一打开的连接是你声明的数据库（只取表结构）与它自己的本机回环状态页
- **不上传**：索引正文由**你自己的代理**在本地通过你已在用的模型通道撰写，
  AOCI 不引入任何新的数据出口
- 状态页**只绑回环地址**，只应答 GET / HEAD，不加锁、不写账本、不改仓库任何字节

## 六、三个执行模式

| 模式 | 行为 |
|---|---|
| **代理原生**（默认） | 宿主模型读证据并创作语义；不需要第二个模型 API |
| **端点原生**（可选） | 用户配置兼容端点起草候选；密钥保留在环境变量 |
| **纯确定性** | 禁用 AI，保留扫描、基线、校验、查询、治理与恢复；新语义仍需模型或人创作 |

## 七、已知限制

- 当前是**发布候选版本**（`v0.1.0-rc14`）——接口可能变，**以运行中二进制为准**
- 绿色结果**只证明结构与治理条件成立**，**不表示每条模型语义都绝对正确**——
  语义仍需源码、schema、测试、运行结果与人工审查验证
- 它不是知识图谱系统：派生观察**不建立第二套权威事实**，冲突时以权威资产为准
- 规模上限由**索引大小**决定，不是代码行数本身
